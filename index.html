Tilevania

Modular 2D tilemap platformer featuring Rule Tiles, Cinemachine camera confining, and persistent game state architecture

A classic 2D action platformer built with Unity's Tilemap ecosystem and the New Input System. Engineered multi-tiered terrain using Composite Colliders and Rule Tiles, layered state machine animations for running, jumping, and ladder climbing, and implemented seamless level streaming through persistent session singletons.

Unity 2D C# Unity Tilemaps Rule Tiles Cinemachine State Machines
  • Authored physics interactions using Composite Colliders, custom Physics Material 2D, and layer-mask checks to eradicate wall-sticking and ensure snappy jump arcs.
  • Framed gameplay with Cinemachine 2D Virtual Cameras and Polygon Confiners to dynamically frame level exploration while preventing off-screen bounds breaks.
  • Constructed a robust GameSession manager using the Singleton pattern and ScenePersist architecture to preserve player lives, coin tallies, and pickup states across level portals.

The Cowboy

Tactical 3D top-down shooter built on Unity's New Input System, featuring dynamic enemy AI and objective extraction

A fast-paced 3D top-down shooter designed around high-stakes combat and dynamic sandbox encounters. Built using modern C# architecture in Unity, players must out-maneuver tactical AI squads, utilize drivable vehicles, and complete time-critical evacuation objectives across low-poly desert canyons.

Unity 3D C# New Input System NavMesh AI Vehicle Mechanics
  • Engineered an expandable weapon system handling modular reload states, ammo economies, bullet physics, and muzzle feedback.
  • Implemented state-driven AI behaviors featuring melee flankers, cover-seeking ranged units, and responsive line-of-sight tracking.
  • Integrated vehicle physics alongside mission objective and extraction timer loops to drive dynamic pacing and player decision-making.
